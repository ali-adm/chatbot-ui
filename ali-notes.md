## Что такое PM2
PM2, или Process Manager 2, — это универсальный и мощный менеджер процессов для приложений Node.js. Он предназначен для упрощения развёртывания, управления и мониторинга приложений Node.js в производственных средах.

### PM2 поставляется с рядом функций:
- Управление процессами
- Мониторинг
- Ведение журнала
- Кластерный режим
- Создание сценария запуска
- Среда и конфигурация
- Управление версиями
- Безопасность
- Управление обновлениями
- Глобальный интерфейс командной строки

Лично я использую его в основном для управления процессами и ведения журналов, что позволяет запускать, останавливать и автоматически перезапускать процессы Node.js.

Вот список часто используемых команд PM2 с примерами:
Запустите Node.js приложение с PM2:   
`pm2 start app.js`  
Запустите приложение NextJS с определенным именем:  
`pm2 start npm --name app-name -- start`  
Список всех процессов PM2:  
`pm2 ls`  
Показать подробную информацию о конкретном процессе:  
`pm2 show your-app-name`  
Просмотр журналов конкретного процесса в режиме реального времени:  
`pm2 logs your-app-name`  
Мониторинг системных ресурсов для всех процессов PM2:  
`pm2 monit`  
-Остановить процесс PM2:  
`pm2 stop your-app-name`  
Перезапустить процесс PM2:  
`pm2 restart your-app-name`  
Удалить процесс PM2:  
`pm2 delete your-app-name`  
Перезагрузите процесс PM2 (перезапуск без простоев):  
`pm2 reload your-app-name`  
Сохраните список процессов PM2 для автоматического запуска:  
`pm2 save`  
Запуск PM2 при загрузке системы:  
`pm2 startup`  
Просмотр подробного состояния всех процессов PM2:  
`pm2 status`  
Очистка журналов для конкретного процесса:  
`pm2 flush your-app-name`  

Эти команды должны охватывать большинство распространённых задач, которые необходимо выполнять при работе с PM2. Для получения более подробной информации вы всегда можете обратиться к официальной документации PM2.

## Переменные в промптах

Подсказка в форме промпта **Chatbot UI**: 

> *"Prompt content. Use {{}} to denote a variable. Ex: {{name}} is a {{adjective}} {{noun}}."*

означает, что в шаблоне промпта можно использовать фигурные скобки `{{}}`, чтобы обозначать **переменные**, которые можно будет заменить конкретными значениями перед выполнением.

### Как это работает:

1. **Переменные** — это значения, которые могут меняться в зависимости от контекста. Например, переменная `{{name}}` может быть заменена на конкретное имя, а `{{adjective}}` и `{{noun}}` — на прилагательное и существительное соответственно.
2. **Пример использования**:
   Допустим, у вас есть шаблон промпта:
   
   ```plaintext
   {{name}} is a {{adjective}} {{noun}}.
   ```

   Когда вы заполняете переменные, вы можете заменить их реальными значениями, например:

   ```plaintext
   Alice is a smart developer.
   ```

   Где:
   - `{{name}}` заменяется на "Alice"
   - `{{adjective}}` заменяется на "smart"
   - `{{noun}}` заменяется на "developer"

3. **Гибкость**:
   Такой подход позволяет вам создавать шаблонные промпты с переменными, которые могут быть динамически заменены разными значениями, что делает промпт универсальным и многоразовым.

Этот механизм удобен для автоматической генерации текста с разными параметрами, обеспечивая высокую гибкость для кастомизации промптов.



## Работа с переменными из промпта

Значения для переменных, обозначенных фигурными скобками `{{}}`, заменяются либо **автоматически** (если это встроено в логику системы или сценарий), либо **вручную**, когда вы сами задаёте значения перед выполнением промпта.

### Как и когда можно заменять значения переменных:
1. **Автоматическая замена переменных**:
   В некоторых системах (в том числе и в Chatbot UI) переменные могут заполняться автоматически на основе данных из контекста. Например, если бот уже знает имя пользователя, он может подставить это значение в переменную `{{name}}`.

   Пример:
   - Промпт: `Hello, {{name}}! How can I assist you today?`
   - Если бот знает, что пользователя зовут Alice, он автоматически заменит `{{name}}` на "Alice":
   - Результат: `Hello, Alice! How can I assist you today?`

2. **Ручная замена переменных**:
   Иногда значения для переменных вам нужно указать вручную. В зависимости от системы, это может быть сделано:
   
   - **До выполнения запроса**: Например, когда вы создаёте шаблон и вводите значения для каждой переменной.
   - **Во время использования**: Перед отправкой запроса вам может быть предложено ввести значения для переменных.

   Пример:
   Допустим, у вас есть следующий шаблон промпта:
   ```plaintext
   {{name}} is a {{adjective}} {{noun}}.
   ```

   При его использовании система может спросить вас заполнить переменные:
   - `{{name}}` → "Bob"
   - `{{adjective}}` → "brilliant"
   - `{{noun}}` → "engineer"

   После этого система создаст итоговую фразу:
   ```plaintext
   Bob is a brilliant engineer.
   ```

### Когда использовать замену:
- **При генерации текста**: Если вы хотите создавать текст с динамическими значениями (например, разные имена, прилагательные, и т. д.), переменные позволяют гибко адаптировать шаблон для разных случаев.
- **Для автоматизации ответов**: Вы можете создать универсальные шаблоны, которые будут заполняться в зависимости от контекста (например, имя пользователя, текущая дата или данные из диалога).

### Как это может быть реализовано в **Chatbot UI**:
1. **Предопределённые сценарии**: В зависимости от контекста взаимодействия с пользователем, Chatbot UI может автоматически подставить нужные данные.
2. **Вручную при настройке промпта**: Если вы создаёте шаблон для запроса или ответа, то перед отправкой система может запросить вас указать значения для переменных. Вы можете заполнить их прямо в интерфейсе перед запуском запроса.

Этот механизм гибок и позволяет использовать один шаблон для разных задач, делая ответы более персонализированными.
